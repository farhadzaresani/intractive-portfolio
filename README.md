# Farhad Zare — Interactive Portfolio

Retro terminal-room portfolio built with **Vite**, **React**, **TypeScript**, and **React Three Fiber**.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Controls

- **ENTER** on the boot screen to enter the room
- Click CRT monitors (or the bottom HUD) for About / Work / Skills / Contact
- **Esc** closes the open panel
